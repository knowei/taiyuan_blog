# 太原博客系统

## 1 目录结构

```
太原博客系统
├─taiyuan-admin         # 主模块
├─taiyuan-common        # 公共模块
├─taiyuan-framwork      # 配置模块
├─taiyuan-front         # 博客后台
├─taiyuan-generator     # 代码生成模块
├─taiyuan-qauarzt       # 定时任务模块
├─taiyuan-system        # 系统模块
└─taxyuan-web           # 博客前台
```
